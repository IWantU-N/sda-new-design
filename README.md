# SDA Desk

Локальный Windows desktop-authenticator с интерфейсом для управления Steam `maFiles`. Проект создан по мотивам сценариев оригинального [Steam Desktop Authenticator](https://github.com/jessecar96/steamdesktopauthenticator), а не является его официальным выпуском или аффилированным приложением.

## Возможности

- Импорт существующих открытых `.maFile` и JSON-файлов.
- Создание `.maFile` вручную из уже имеющихся данных аутентификатора.
- Привязка мобильного аутентификатора через Steam: логин, пароль, Steam Guard-код из почты, запрос номера/SMS при необходимости и повторный ввод revocation code.
- Автоматическая генерация и копирование кода Steam Guard.
- Просмотр подтверждений обменов, продаж и покупок Community Market сразу по выбранным аккаунтам; выбранные пункты можно подтвердить или отклонить одним действием.
- Экспорт открытого `.maFile` для резервного копирования.
- Локальное хранение аккаунтов в подпапке `maFiles` рядом с запущенным `.exe`.

Файлы сохраняются **без шифрования**, по запросу пользователя. Они содержат ключи аутентификатора и токены сессии для подтверждений; уязвимое устройство или доступ другого пользователя к папке приложения может привести к потере аккаунта. Сделай резервную копию и не передавай `.maFile` другим людям.

Пароль Steam используется только во время входа и не сохраняется. Для входа Steam может запросить код из почты или код текущего аутентификатора. Привязка может потребовать подтверждённый номер телефона: Steam отправляет SMS-код для активации, а при добавлении нового номера может прислать письмо со ссылкой подтверждения. Аккаунт появится в списке только после успешной активации и повторного ввода revocation code.

Пока активация не завершена, приложение временно записывает незашифрованный файл в подпапку `pending` рядом с `.exe`. Если привязка прервётся во время активации, оставь этот файл на месте, пока не проверишь статус аутентификатора в Steam. Завершённые `maFiles` хранятся в подпапке `maFiles` рядом с `.exe`.

Подтверждения обменов и продаж доступны для `.maFile`, в котором есть `identity_secret`, `device_id` и актуальная сессия. Экран загружает список для всех отмеченных аккаунтов, группирует массовые действия отдельно для каждого аккаунта и показывает итоговый список перед отправкой. Приложение не выполняет действия автоматически.

Код протокола SteamAuth включён из [MIT-репозитория geel9/SteamAuth](https://github.com/geel9/SteamAuth), лицензия находится в `lib/SteamAuth/LICENSE`. Приложение не связано с Valve или Steam.

## Запуск

Требуется Windows и .NET 10 SDK. Для сборки исходника также нужен доступ к NuGet.

```powershell
dotnet run
```

Сборка:

```powershell
dotnet build
```
